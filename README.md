# neo-minyo
Suno & AI sound generation for Japanese folk songs (min-yoh). Includes 14 curated tracks with game scores for board-game integration.

## Project Structure
- **README.md** - This overview
- **minyo-game-design.md** - Game design document for Tokyo Odori board game
- **minyo-db/** (submodule or reference) - Database of song metadata, scores, and regional statistics

## Features
- 14 traditional Japanese folk songs with region-specific themes
- Game scoring system based on population, tourism, and fame metrics
- Board game mechanics for "Tokyo Odori" - a folk song collection game
- Integration with Suno AI for music generation capabilities
- Zine and YouTube content planning materials

## Game Overview
Players travel through Tokyo districts by playing folk songs, earning points based on:
- Population data (weighted 40%)
- Tourism statistics (weighted 40%) 
- Song fame/media exposure (weighted 20%)

The goal is to reach the Grand Finale (Tokyo Tower) with the highest score by collecting "Odori Tokens" from each district.
